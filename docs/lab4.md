# Лабораторная работа №4

Однопросмотровый ассемблер для программы в абсолютном формате.

## Задание

Сделать то же, что в лабе 1, но исходный текст читается один раз. Результат должен совпасть с лабой 1.

- Код формируется сразу при чтении строки.
- Если адрес метки в операнде ещё неизвестен, в код ставится заглушка, а в ТСИ запоминается, в какой команде эта метка нужна.
- Когда встречается строка с этой меткой, адрес вписывается во все запомненные команды.
- На `End` проверить, что не осталось меток без адреса.

Окно:
- вспомогательной таблицы нет, кнопок прохода тоже;
- ТСИ из трёх столбцов: имя, адрес, адреса команд, где имя использовано до определения;
- кнопки «Один шаг», «Запуск / продолжить», «Перезапуск»;
- текущая строка исходного текста подсвечивается.

## Обработка строки

Метка в начале строки:
- метки нет в ТСИ - добавить с текущим адресом;
- метка есть без адреса - записать адрес и вписать его во все команды, где она использована;
- метка есть с адресом - ошибка «метка определена дважды».

Метка в операнде:
- адрес известен - подставить сразу;
- адрес неизвестен - поставить заглушку `····` и запомнить адрес команды.

## Пример

Программа «Без ошибок» из [лабы 1](lab1.md).

| Шаг | Строка | Что происходит | Код |
|---|---|---|---|
| 1 | `Exampl Start 1000` | счётчик = 1000 | |
| 2 | `LD R1 One` | One неизвестна, ждёт в 1000 | 05 01 ···· |
| 3 | `LD R2 Two` | Two неизвестна, ждёт в 1004 | 05 02 ···· |
| 4 | `ADD R1 R2` | | 0C 12 |
| 5 | `SAV R1 Rez` | Rez неизвестна, ждёт в 100A | 09 01 ···· |
| 6 | `CALL Show` | Show неизвестна, ждёт в 100E | 19 ···· |
| 7 | `HALT` | | 24 |
| 8 | `Show INT 5` | Show = 1012, вписать в 100E | 1C 05; 100E: 19 1012 |
| 9 | `RET` | | 20 |
| 10 | `One WORD 1` | One = 1015, вписать в 1000 | 0001; 1000: 05 01 1015 |
| 11 | `Two WORD 2` | Two = 1017, вписать в 1004 | 0002; 1004: 05 02 1017 |
| 12 | `Rez WORD ?` | Rez = 1019, вписать в 100A | резерв; 100A: 09 01 1019 |
| 13 | `Text BYTE "Hello"` | Text = 101B | 48 65 6C 6C 6F |
| 14 | `End` | меток без адреса нет | заголовок `Exampl 0020 1000` |

Итоговый код такой же, как в лабе 1.

## Новые ошибки

- на `End` осталась метка без адреса - «метка не определена».

## Контрольные вопросы

**Чем отличается от лабы 1?** Текст читается один раз, адреса меток, которые ниже, дописываются потом. Результат тот же.

**Что добавилось в ТСИ?** Столбец с адресами команд, которые ждут адрес этой метки.

**Когда становится понятно, что метка не определена?** Только на `End`, до этого она могла встретиться ниже.

**Что лучше, один проход или два?** Один проход быстрее, но весь код нужно хранить в памяти, чтобы потом исправлять.
