# Лабораторная работа №1

Двухпросмотровый ассемблер для программы в абсолютном формате.

## Задание

Написать программу с окном, которая по исходному тексту и ТКО выполняет два прохода ассемблера и показывает промежуточные и итоговые таблицы.

Требования:
- окно из трёх частей и кнопки «Первый проход» и «Второй проход»;
- исходный текст и ТКО редактируются, строки можно вставлять и удалять;
- адрес загрузки задаётся пользователем;
- все адреса в 16-ричном виде;
- 4 формата команд;
- команды переводятся в битовое представление на первом проходе;
- метки проверяются на зарезервированные слова;
- второй проход доступен только после успешного первого;
- есть примеры без ошибок и с ошибками.

Формат команд описан в [assignment.md](assignment.md#формат-команд).

## Окно

```
+----------------------+-------------------------+-----------------------+
| Исходный текст       | Вспомогательная таблица | Двоичный код          |
| ТКО                  | ТСИ                     | (H, T, E)             |
| Адрес загрузки       | Ошибки 1-го прохода     | Ошибки 2-го прохода   |
+----------------------+-------------------------+-----------------------+
 [Первый проход] [Второй проход]                          Пример: [   v]
```

## ТКО по умолчанию

| Команда | Код | Длина | Операнды |
|---|---|---|---|
| LD | 01 | 4 | регистр, метка |
| SAV | 02 | 4 | регистр, метка |
| ADD | 03 | 2 | регистр, регистр |
| SUB | 04 | 2 | регистр, регистр |
| JUMP | 05 | 3 | метка |
| CALL | 06 | 3 | метка |
| INT | 07 | 2 | число |
| RET | 08 | 1 | - |
| HALT | 09 | 1 | - |

## Пример «Без ошибок»

```
Exampl  Start  001000
        LD     R1  One
        LD     R2  Two
        ADD    R1  R2
        SAV    R1  Rez
        CALL   Show
        HALT
Show    INT    5
        RET
One     WORD   1
Two     WORD   2
Rez     WORD   ?
Text    BYTE   "Hello"
        End
```

### Первый проход

Счётчик адреса начинается с `001000` и после каждой строки увеличивается на её длину. Мнемоника команды заменяется МКОП - первым байтом, который собирается из битов: код операции из ТКО (6 бит) и тип адресации (2 бита). Операнды пока остаются как в исходном тексте, метки в них заменит адресами второй проход.

| Адрес | МКОП | Операнд 1 | Операнд 2 |
|---|---|---|---|
| 001000 | 05 | R1 | One |
| 001004 | 05 | R2 | Two |
| 001008 | 0C | R1 | R2 |
| 00100A | 09 | R1 | Rez |
| 00100E | 19 | Show | |
| 001011 | 24 | | |
| 001012 | 1C | 5 | |
| 001014 | 20 | | |
| 001015 | WORD | 1 | |
| 001017 | WORD | 2 | |
| 001019 | WORD | ? | |
| 00101B | BYTE | "Hello" | |

Как получается МКОП:

| Команда | Код в ТКО | Биты | Адресация | МКОП |
|---|---|---|---|---|
| LD | 01 | 000001 | 01 - прямая | 000001 01 = 05 |
| ADD | 03 | 000011 | 00 - без адреса | 000011 00 = 0C |
| SAV | 02 | 000010 | 01 - прямая | 000010 01 = 09 |
| CALL | 06 | 000110 | 01 - прямая | 000110 01 = 19 |
| HALT | 09 | 001001 | 00 - без адреса | 001001 00 = 24 |
| INT | 07 | 000111 | 00 - без адреса | 000111 00 = 1C |
| RET | 08 | 001000 | 00 - без адреса | 001000 00 = 20 |

ТСИ:

| Метка | Адрес |
|---|---|
| Show | 001012 |
| One | 001015 |
| Two | 001017 |
| Rez | 001019 |
| Text | 00101B |

Конец программы - `001020`, длина `000020`.

### Второй проход

Вместо заглушек подставляются адреса из ТСИ.

Двоичный код показан записями объектного модуля. Тип записи: `H` - заголовок, `T` - строка кода, `E` - конец модуля и точка входа (адрес, с которого начинается выполнение, - адрес загрузки). Заголовок объектного модуля - первая строка `H`: адрес загрузки `001000`, длина `000020`, имя `Exampl`, поэтому отдельной таблицы для заголовка нет.

| Тип | Адрес | Длина | Машинный код | Команда |
|---|---|---|---|---|
| H | 001000 | 000020 | Exampl | Start |
| T | 001000 | 04 | 05 01 1015 | LD R1 One |
| T | 001004 | 04 | 05 02 1017 | LD R2 Two |
| T | 001008 | 02 | 0C 12 | ADD R1 R2 |
| T | 00100A | 04 | 09 01 1019 | SAV R1 Rez |
| T | 00100E | 03 | 19 1012 | CALL Show |
| T | 001011 | 01 | 24 | HALT |
| T | 001012 | 02 | 1C 05 | INT 5 |
| T | 001014 | 01 | 20 | RET |
| T | 001015 | 02 | 0001 | WORD 1 |
| T | 001017 | 02 | 0002 | WORD 2 |
| T | 001019 | 02 | | WORD ? (резерв) |
| T | 00101B | 05 | 48 65 6C 6C 6F | BYTE "Hello" |
| E | 001000 | | | End |

Если поменять адрес загрузки на `002000`, все адреса сдвинутся: `05 01 2015` и т.д.

## Проверяемые ошибки

ТКО:
- пустая ячейка;
- повтор мнемоники или кода;
- код не hex или больше `3F`;
- длина не от 1 до 4;
- мнемоника совпадает с директивой или регистром.

Первый проход:
- нет `Start` в начале или нет `End`;
- неверный адрес загрузки (не hex, больше 00FFFF или равен 0; ведущие нули можно: 1000 = 001000);
- повтор метки, метка совпадает с зарезервированным словом;
- команды нет в ТКО;
- операнды не подходят к формату команды;
- неверное значение в `WORD` или `BYTE`;
- выход за пределы памяти `00FFFF`;
- строки после `End`.

Второй проход:
- метка не определена.

Строки с ошибками подсвечиваются, в сообщении указан номер строки.

В списке «Пример» есть программа без ошибок и 11 программ с ошибками, в том числе с несколькими ошибками сразу.

## Контрольные вопросы

**Зачем два прохода?** Метки могут использоваться раньше, чем определены. Первый проход находит адреса всех меток, второй подставляет их.

**Что делает первый проход?** Считает адреса строк, заполняет ТСИ и заменяет мнемоники на МКОП - первый байт команды в битовом представлении. Результат - вспомогательная таблица: адрес, МКОП, операнды.

**Что в столбце МКОП?** Первый байт команды: код из ТКО, сдвинутый на 2 бита (умножить на 4), плюс тип адресации. У данных там `WORD` или `BYTE`.

**Что делает второй проход?** Подставляет адреса меток из ТСИ и формирует объектный модуль.

**Какие форматы команд?** Четыре, формат равен длине: 1 байт - без операндов, 2 - регистры или число, 3 - адрес, 4 - регистр и адрес.

**Как собирается первый байт?** Старшие 6 бит - код операции, младшие 2 - тип адресации. `LD` = `000001`, прямая = `01`, получается `00000101` = `05`.

**Почему код операции не больше 3F?** На него отведено 6 бит, `3F` = `111111`.

**Почему адрес One равен 001015?** Перед ней команды длиной 4+4+2+4+3+1+2+1 = 21 = `15h` байт, начало программы `001000`.

**Что за буквы H, T, E в двоичном коде?** Это типы записей объектного модуля: H - заголовок (имя, адрес загрузки, длина), T - строка кода (адрес, длина, байты), E - конец модуля и точка входа.

**Почему в таблицах адрес из 6 цифр, а в коде команды из 4?** В таблицах все адреса пишутся 6 цифрами. Внутри команды под адрес отведено 2 байта (4 цифры): иначе `LD R1 One` (код, регистр и адрес) не поместится в 4 байта, а форматов команд по заданию 4, самый длинный - 4 байта. Память 64 КБ, адреса 000000-00FFFF.

**Почему программа абсолютная?** Все адреса посчитаны от `001000`, по другому адресу она работать не будет.

**Какие слова нельзя использовать как метки?** Регистры `R0`–`R15`, директивы `Start`, `End`, `WORD`, `BYTE` и команды из ТКО.
