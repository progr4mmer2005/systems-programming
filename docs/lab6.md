# Лабораторная работа №6

Однопросмотровый ассемблер, раздельное ассемблирование (полный перемещаемый формат).

## Задание

Объединить лабу 5 и лабу 3: текст читается один раз, есть `EXTDEF`, `EXTREF`, таблица внешних имён, список внешних ссылок, таблица настройки из двух столбцов и сохранение в файл. Результат должен совпасть с лабой 3.

Особенности одного прохода:
- `EXTDEF` стоит в начале, а сами метки ниже. На строке `EXTDEF` имена заносятся в ТСИ без адреса с признаком внешнего имени, адрес появляется, когда встретится метка.
- `EXTREF` тоже стоит в начале, поэтому при использовании внешней ссылки уже известно, что это она. В код пишутся нули, в таблицу настройки - адрес команды и имя. Запоминать команду не нужно: адрес ссылки в этом модуле не появится.
- На `End` проверить, что у всех имён из `EXTDEF` есть адрес.

## Пример

Программа из [лабы 3](lab3.md).

| Шаг | Строка | Что происходит | Код |
|---|---|---|---|
| 1 | `first Start 0` | счётчик = 0 | |
| 2 | `EXTDEF buf Str1` | buf и Str1 в ТСИ без адреса, внешние | |
| 3 | `EXTREF Str2` | Str2 - внешняя ссылка | |
| 4 | `Proc LD R1 Str3` | Proc = 0000, Str3 неизвестна; настройка 0000 | 05 01 ···· |
| 5 | `LD R2 Str2` | внешняя ссылка; настройка 0004 Str2 | 05 02 0000 |
| 6 | `ADD R1 R2` | | 0C 12 |
| 7 | `SAV R1 [Rez]` | относительная, Rez неизвестна, следующая 000E | 0A 01 ···· |
| 8 | `JUMP Proc` | Proc известна; настройка 000E | 15 0000 |
| 9 | `Str1 WORD 3` | Str1 = 0011 | 0003 |
| 10 | `Str3 WORD 1` | Str3 = 0013, вписать в 0000 | 0001; 0000: 05 01 0013 |
| 11 | `Rez WORD ?` | Rez = 0015, смещение 0015 − 000E = 0007 | 0A 01 0007 |
| 12 | `buf BYTE "Hello!"` | buf = 0017 | 48 65 6C 6C 6F 21 |
| 13 | `End` | у buf и Str1 есть адреса, длина 001D | заголовок `first 001D 0000` |

Итог такой же, как в лабе 3: таблица настройки `0000`, `0004 Str2`, `000E`, внешние имена `Str1 0011`, `buf 0017`.

## Новые ошибки

- на `End` у имени из `EXTDEF` нет адреса;
- остальные ошибки как в лабах 3 и 5.

## Контрольные вопросы

**Чем отличается от лабы 3?** Результат тот же, но текст читается один раз, а адреса дописываются потом.

**Почему имена из EXTDEF сначала без адреса?** Они объявляются в начале, а метки стоят ниже.

**Почему для внешней ссылки не нужно запоминать команду?** Её адрес в этом модуле не появится, его подставят при компоновке. Достаточно записи в таблице настройки.
