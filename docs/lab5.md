# Лабораторная работа №5

Однопросмотровый ассемблер для программы в перемещаемом формате.

## Задание

Объединить лабу 4 и лабу 2: текст читается один раз, программа транслируется с нуля, есть таблица настройки и относительная адресация. Результат должен совпасть с лабой 2.

- `Start 0`.
- Окно как в лабе 4, плюс таблица настройки.
- Примеры: только прямая адресация, только относительная, смешанная.

## Обработка команд с меткой

Прямая адресация:
- адрес команды сразу заносится в таблицу настройки (сам адрес метки для этого не нужен);
- метка известна - подставить адрес, неизвестна - заглушка и запомнить команду.

Относительная адресация:
- в таблицу настройки не заносится;
- метка известна (она выше) - сразу посчитать смещение, оно будет отрицательным;
- метка неизвестна - заглушка, и запомнить, что это относительная команда и адрес следующей за ней команды.

Когда метка определена, для каждой запомненной команды:
- прямая - вписать адрес;
- относительная - вписать смещение = адрес метки − адрес следующей команды.

## Пример

```
Exampl  Start  0
Loop    LD     R1  One
        SAV    R1  [Rez]
        JUMP   Loop
One     WORD   1
Rez     WORD   ?
        End
```

| Шаг | Строка | Что происходит | Настройка | Код |
|---|---|---|---|---|
| 1 | `Loop LD R1 One` | Loop = 0000, One неизвестна | 0000 | 05 01 ···· |
| 2 | `SAV R1 [Rez]` | относительная, Rez неизвестна, следующая команда 0008 | 0000 | 0A 01 ···· |
| 3 | `JUMP Loop` | Loop известна | 0000, 0008 | 15 0000 |
| 4 | `One WORD 1` | One = 000B, вписать адрес в 0000 | 0000, 0008 | 0001; 0000: 05 01 000B |
| 5 | `Rez WORD ?` | Rez = 000D, вписать смещение 000D − 0008 = 0005 в 0004 | 0000, 0008 | 0A 01 0005 |
| 6 | `End` | всё определено, длина 000F | 0000, 0008 | заголовок `Exampl 000F 0000` |

## Контрольные вопросы

**Чем отличается от лабы 4?** Программа с нуля, есть таблица настройки и относительная адресация.

**Почему команду с прямой адресацией можно сразу занести в таблицу настройки?** Таблице важно только место, где будет адрес, а не сам адрес.

**Что делать, если метка для относительной команды ниже?** Запомнить адрес следующей команды и потом вписать смещение, а не адрес.

**Совпадёт ли результат с лабой 2?** Да.
