# Лабораторная работа №2

Двухпросмотровый ассемблер для программы в перемещаемом формате.

## Задание

Доработать лабу 1 так, чтобы программу можно было загрузить по любому адресу.

- Программа транслируется с нуля: `Start 0`.
- В правую часть окна добавить таблицу настройки.
- Добавить относительную адресацию: операнд пишется в квадратных скобках, `LD R1 [One]`, тип адресации в первом байте - `10`.
- На втором проходе:
  - прямая адресация - подставить адрес метки и занести адрес команды в таблицу настройки;
  - относительная адресация - записать смещение, в таблицу настройки не заносить.
- Примеры: только прямая адресация, только относительная, смешанная.

Смещение = адрес метки − адрес следующей команды. Адрес следующей команды = адрес команды + её длина. Отрицательное смещение записывается в дополнительном коде (−6 = `FFFA`).

Команды без адреса (`ADD`, `INT`, `HALT`, `RET`) и данные (`WORD`, `BYTE`) в таблицу настройки не попадают.

## Пример: только прямая адресация

Та же программа, что в лабе 1, но с `Start 0`.

| Адрес | Строка | Код |
|---|---|---|
| 0000 | `LD R1 One` | 05 01 0015 |
| 0004 | `LD R2 Two` | 05 02 0017 |
| 0008 | `ADD R1 R2` | 0C 12 |
| 000A | `SAV R1 Rez` | 09 01 0019 |
| 000E | `CALL Show` | 19 0012 |
| 0011 | `HALT` | 24 |
| 0012 | `Show INT 5` | 1C 05 |
| 0014 | `RET` | 20 |
| 0015 | `One WORD 1` | 0001 |
| 0017 | `Two WORD 2` | 0002 |
| 0019 | `Rez WORD ?` | резерв |
| 001B | `Text BYTE "Hello"` | 48 65 6C 6C 6F |

Заголовок: `Exampl 0020 0000`.

Таблица настройки: `0000`, `0004`, `000A`, `000E`.

Если загрузить программу с адреса `5000`, загрузчик пройдёт по таблице настройки и прибавит `5000` к адресам в этих командах: `05 01 0015` станет `05 01 5015`.

## Пример: относительная адресация

Те же строки, но метки в скобках: `LD R1 [One]`, `LD R2 [Two]`, `SAV R1 [Rez]`, `CALL [Show]`. Адреса те же.

| Адрес | Строка | Смещение | Код |
|---|---|---|---|
| 0000 | `LD R1 [One]` | 0015 − 0004 = 0011 | 06 01 0011 |
| 0004 | `LD R2 [Two]` | 0017 − 0008 = 000F | 06 02 000F |
| 000A | `SAV R1 [Rez]` | 0019 − 000E = 000B | 0A 01 000B |
| 000E | `CALL [Show]` | 0012 − 0011 = 0001 | 1A 0001 |

Первый байт `LD` здесь `000001 10` = `06`. Таблица настройки пустая.

## Пример: смешанная адресация

Часть меток в скобках, часть без. В таблицу настройки попадают только команды с прямой адресацией. Пример перехода назад:

```
Exampl  Start  0
Loop    LD     R1  One        0000  05 01 000B
        SAV    R1  [Rez]      0004  0A 01 0005   (000D - 0008)
        JUMP   [Loop]         0008  16 FFF5      (0000 - 000B = -B)
One     WORD   1              000B  0001
Rez     WORD   ?              000D
        End                   длина 000F
```

Таблица настройки: `0000`.

## Новые ошибки

- адрес в `Start` не равен 0;
- неверная запись операнда в скобках.

## Контрольные вопросы

**Что такое перемещаемая программа?** Программа, которую можно загрузить по любому адресу. Она транслируется с нуля, а при загрузке адреса в ней сдвигаются.

**Что такое таблица настройки?** Список адресов команд, в которых записан прямой адрес. При загрузке к этим адресам прибавляется адрес загрузки.

**Почему команды с относительной адресацией не попадают в таблицу настройки?** В них записано смещение, а не адрес. При сдвиге всей программы смещение не меняется.

**Почему смещение считается от следующей команды?** Когда процессор выполняет команду, счётчик команд уже указывает на следующую.

**Как записывается отрицательное смещение?** В дополнительном коде в 2 байтах: −B = `FFF5`.
