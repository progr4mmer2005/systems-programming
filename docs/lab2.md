# Лабораторная работа №2

Двухпросмотровый ассемблер для программы в перемещаемом формате.

## Задание

Доработать лабу 1 так, чтобы программу можно было загрузить по любому адресу.

- Программа транслируется с нуля: `Start 0` или `Start` без адреса.
- В правую часть окна добавить таблицу настройки.
- Добавить относительную адресацию: операнд пишется в квадратных скобках, `LD R1 [One]`, тип адресации в первом байте - `10`.
- На втором проходе:
  - прямая адресация - подставить адрес метки и занести адрес команды в таблицу настройки;
  - относительная адресация - записать смещение, в таблицу настройки не заносить.
- Примеры: только прямая адресация, только относительная, смешанная.

Смещение = адрес метки − адрес следующей команды. Адрес следующей команды = адрес команды + её длина. Отрицательное смещение записывается в дополнительном коде (−14h = `FFEC`).

Команды без адреса (`ADD`, `INT`, `HALT`, `RET`) и данные (`WORD`, `BYTE`) в таблицу настройки не попадают.

## Окно

Как в лабе 1, справа добавилась таблица настройки:

```
+----------------------+-------------------------+-----------------------+
| Исходный текст       | Вспомогательная таблица | Заголовок             |
|                      |                         | Таблица настройки     |
| ТКО                  | ТСИ                     | Двоичный код          |
| Адрес загрузки       | Ошибки 1-го прохода     | Ошибки 2-го прохода   |
+----------------------+-------------------------+-----------------------+
 [Первый проход] [Второй проход]                          Пример: [   v]
```

В таблице настройки для каждой строки видна команда, щелчок по строке подсвечивает её в исходном тексте. Во вспомогательной таблице у относительной адресации в МКОП младшие биты `10`: `LD R2 [Two]` - `06`, а `LD R1 One` - `05`.

## Пример: только прямая адресация

Та же программа, что в лабе 1, но с `Start 0`.

| Адрес | Строка | Код |
|---|---|---|
| 0000 | `LD R1 One` | 05 01 0015 |
| 0004 | `LD R2 Two` | 05 02 0017 |
| 0008 | `ADD R1 R2` | 0C 12 |
| 000A | `SAV R1 Rez` | 09 01 0019 |
| 000E | `CALL Show` | 19 0012 |
| 0011 | `HALT` | 24 |
| 0012 | `Show INT 5` | 1C 05 |
| 0014 | `RET` | 20 |
| 0015 | `One WORD 1` | 0001 |
| 0017 | `Two WORD 2` | 0002 |
| 0019 | `Rez WORD ?` | резерв |
| 001B | `Text BYTE "Hello"` | 48 65 6C 6C 6F |

Заголовок: `Exampl 0020 0000`.

Таблица настройки: `0000`, `0004`, `000A`, `000E`.

Если загрузить программу с адреса `5000`, загрузчик пройдёт по таблице настройки и прибавит `5000` к адресам в этих командах: `05 01 0015` станет `05 01 5015`.

## Пример: только относительная адресация

Те же строки, но метки в скобках: `LD R1 [One]`, `LD R2 [Two]`, `SAV R1 [Rez]`, `CALL [Show]`. Адреса те же.

| Адрес | Строка | Смещение | Код |
|---|---|---|---|
| 0000 | `LD R1 [One]` | 0015 − 0004 = 0011 | 06 01 0011 |
| 0004 | `LD R2 [Two]` | 0017 − 0008 = 000F | 06 02 000F |
| 000A | `SAV R1 [Rez]` | 0019 − 000E = 000B | 0A 01 000B |
| 000E | `CALL [Show]` | 0012 − 0011 = 0001 | 1A 0001 |

Первый байт `LD` здесь `000001 10` = `06`. Таблица настройки пустая.

## Пример: смешанная адресация

Часть меток в скобках, часть без. Вместо `HALT` стоит переход назад `JUMP [Loop]`, чтобы было видно отрицательное смещение.

```
Exampl  Start  0
Loop    LD     R1  One       0000  05 01 0017
        LD     R2  [Two]     0004  06 02 0011   (0019 - 0008)
        ADD    R1  R2        0008  0C 12
        SAV    R1  [Rez]     000A  0A 01 000D   (001B - 000E)
        CALL   Show          000E  19 0014
        JUMP   [Loop]        0011  16 FFEC      (0000 - 0014 = -14h)
Show    INT    5             0014  1C 05
        RET                  0016  20
One     WORD   1             0017  0001
Two     WORD   2             0019  0002
Rez     WORD   ?             001B  резерв
Text    BYTE   "Hello"       001D  48 65 6C 6C 6F
        End                  длина 0022
```

Таблица настройки: `0000` (`LD R1 One`), `000E` (`CALL Show`).

Двоичный код в окне показан записями объектного модуля, как в лабе 1: `H` - заголовок, `T` - строки кода с адресом и длиной, `E` - конец модуля.

## Проверяемые ошибки

Все ошибки лабы 1, кроме адреса загрузки, плюс:
- адрес в `Start` не 0;
- `[метка]` у команды без адреса (формат 1 или 2), например `ADD R1 [R2]`;
- неверная запись операнда в скобках, например `[Rez`;
- смещение не помещается в 2 байта.

В списке «Пример» три правильные программы (прямая, относительная, смешанная адресация) и 13 программ с ошибками.

## Контрольные вопросы

**Что такое перемещаемая программа?** Программа, которую можно загрузить по любому адресу. Она транслируется с нуля, а при загрузке адреса в ней сдвигаются.

**Что такое таблица настройки?** Список адресов команд, в которых записан прямой адрес. При загрузке к адресам в этих командах прибавляется адрес загрузки.

**Почему команды с относительной адресацией не попадают в таблицу настройки?** В них записано смещение, а не адрес. При сдвиге всей программы смещение не меняется.

**Почему смещение считается от следующей команды?** Когда процессор выполняет команду, счётчик команд уже указывает на следующую.

**Как записывается отрицательное смещение?** В дополнительном коде в 2 байтах: −14h = `FFEC`.

**Чем отличается первый байт при прямой и относительной адресации?** Младшими двумя битами: `01` - прямая, `10` - относительная. `LD R1 One` - `05`, `LD R1 [One]` - `06`.
