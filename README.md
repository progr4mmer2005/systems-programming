## Сборка и запуск

Нужен только компилятор g++ (MinGW), библиотеки ставить не надо.

В VS Code открыть папку репозитория, открыть `labN.cpp` и нажать Ctrl+Alt+N (Code Runner). Собирается только `labN.cpp`, остальные файлы `.h` - его части, отдельно они не компилируются. Также работают Ctrl+Shift+B (сборка) и F5 (сборка и запуск). Готовый exe кладётся в `labN/bin/`.

Вручную (Git Bash):

```bash
cd lab1
mkdir -p bin
g++ lab1.cpp -o bin/lab1
./bin/lab1
```

В Git Bash пути пишутся через `/`, путь вида `C:\...\lab1.exe` без кавычек не сработает.

## Структура папки лабы

| Файл / папка | Что там |
|---|---|
| `labN.cpp` | главный файл, собирается только он |
| `config.h` | название лабы и настройки |
| `examples.h` | примеры программ (без ошибок и с ошибками) |
| `asm/` | ассемблер: форматы команд, ТКО, первый и второй проход |
| `app/` | окно: кнопки, раскладка, обработчики |
| `ui/` | таблица, кнопки, темы, шрифты |
| `util/` | работа со строками и числами |
| `platform/` | служебный код для Windows |

## Управление в окне

- F5 - первый проход, F6 - второй проход.
- После прохода любые изменения исходного текста, ТКО или адреса загрузки сразу пересчитываются: если был выполнен первый проход, заново выполняется первый, если второй - оба.
- Двойной клик или Enter - редактировать ячейку.
- Правый клик по таблице - вставить строку выше или ниже, удалить строку, очистить ячейку.
- "Редактировать как текст" (правый клик или Ctrl+E) - вся таблица открывается как обычный текст, можно вставить программу целиком. Столбцы разделяются пробелами или Tab, строка с отступа - без метки. Ctrl+Enter - применить, Esc - отмена.
- Список «Пример» - выбор готовой программы.
- Кнопка вверху справа переключает светлую и тёмную тему.
